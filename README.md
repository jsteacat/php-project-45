# Brain Games

Набор из пяти консольных игр для тренировки мозга. В каждой игре нужно правильно ответить на три вопроса подряд. Неверный ответ завершает игру.

## Игры

- `brain-even` — чётное ли число
- `brain-calc` — результат арифметического выражения
- `brain-gcd` — наибольший общий делитель двух чисел
- `brain-progression` — пропущенное число в прогрессии
- `brain-prime` — простое ли число

## Требования

- PHP >= 8.2
- Composer
- Make
- Linux / macOS / WSL

## Установка

```bash
git clone https://github.com/jsteacat/php-project-45.git
cd php-project-45
make install
```

## Запуск

```bash
make brain-games
make brain-even
make brain-calc
make brain-gcd
make brain-progression
make brain-prime
```
